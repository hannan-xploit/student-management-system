# 🎓 Student Management System

A beginner-friendly **Python Student Management System** built to practice functions, loops, nested dictionaries, conditions, and dictionary methods.

## 🚀 Features

* Show all students
* Search for a student
* Add a new student
* Update student marks
* Delete a student
* Calculate total and average marks
* Show final Pass/Fail results
* Menu-driven interface

## 🧠 Concepts Practiced

* Python Functions
* `while` loops
* `for` loops
* Nested Dictionaries
* `.items()`
* `.update()`
* `.pop()`
* `in` operator
* Conditional statements
* User Input
* Basic data manipulation

## 📊 Example Data

The system stores:

* Student name
* Age
* City
* Math marks
* English marks
* Science marks

Example:

```python
"Ali": {
    "age": 20,
    "city": "Lahore",
    "marks": {
        "Math": 90,
        "English": 80,
        "Science": 85
    }
}
```

## ▶️ How to Run

Make sure Python is installed.

```bash
python3 student_management.py
```

Then select an option from the menu.
